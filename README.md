# Agent Izakaya

[English](./README.md) | [日本語](./README.ja.md)

A local-first izakaya retrospective where project agents share stories grounded in session history.

## Status

Early development. This repository currently contains the project brief and issue-driven workflow; the first runnable demo is being implemented in a dedicated issue. Planned features are not available yet.

## Development

See [vision](docs/VISION.md), [workflow](docs/WORKFLOW.md), and [issues](https://github.com/ryoryo34/agent-izakaya/issues). One issue corresponds to one Codex session and one implementation branch. Setup instructions will be added with the runnable demo.
