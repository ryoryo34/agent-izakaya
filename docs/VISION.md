# Agent Izakaya

## 構想

今日・今週などの期間を指定し、プロジェクトごとの担当AIと大将が居酒屋で成果、反省、愚痴、解決策を話す。別プロジェクトの知見が課題解決につながり、大将が繰り返す問題を指摘する。ユーザーも話に参加できる。会話は創作表現だが、事実は選択したセッションの根拠に結び付ける。最後はお会計として持ち帰る知見・明日の一手・積み残しをまとめる。

## 最初の到達点

明示的に選択した履歴と期間から、担当2〜3人と大将の会話・根拠・お会計を一画面で体験できる、APIキー不要のローカルデモを作る。まず体験とデータ境界を検証し、本物のLLMと各CLIの履歴取り込みは独立した後続Issueにする。
